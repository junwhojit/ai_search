인공지능과 탐색

탐색은 문제 상황에서 답을 찾아가는 과정이다. 아래 두 문제 — 미로 찾기와 전구 켜기 — 는 서로 다른 상황이지만 똑같이 초기 상태에서 목표 상태까지의 경로를 찾는 탐색 문제다. 직접 조작해 보면서 상태, 수행 작업, 탐색 전략이라는 개념이 실제로 어떻게 작동하는지 확인해 보자.

용어 정리 glossary

아래 8개 용어는 두 문제 모두에 공통으로 쓰이는 탐색의 기본 개념이다. 시뮬레이터를 조작하다가 헷갈리면 이 표로 돌아와 확인해 보자.

용어쉬운 설명미로 찾기 비유전구 켜기 비유
탐색 문제의 답을 찾아 이리저리 시도해보는 과정. "이렇게 해볼까? 저렇게 해볼까?" 하며 정답에 다가가는 것 마우스가 미로에서 출구를 찾아 헤매는 것 스위치를 이것저것 눌러보며 전구를 모두 켜는 방법을 찾는 것
상태 어떤 순간의 "모습" 한 장. 사진 한 장을 찍었다고 생각하면 된다 지금 마우스가 미로의 어느 칸에 있는 모습 지금 전구가 어떤 것은 켜지고 어떤 것은 꺼진 모습 (예: 1101)
상태 공간 있을 수 있는 "모습 사진"을 전부 모아놓은 앨범 미로의 모든 칸 각각에 마우스가 있을 수 있는 경우 전부 전구 4개가 만들 수 있는 모든 경우 = 16장의 사진(0000~1111)
초기 상태 앨범의 첫 페이지, 시작할 때의 사진 마우스가 출발점에 서 있는 모습 전구가 다 꺼진 모습(0000)
목표 상태 우리가 찾고 싶은 "완성된 사진" 마우스가 도착점에 서 있는 모습 전구가 다 켜진 모습(1111)
상태공간트리 사진들을 "이 사진에서 이렇게 하면 저 사진이 된다"는 식으로 나뭇가지처럼 이어 그린 지도 출발점에서 한 칸씩 움직일 때마다 가지가 뻗어나가는 그림 0000에서 시작해 스위치를 누를 때마다 가지가 뻗어나가는 그림
노드 트리에서 사진 한 장(=상태)을 나타내는 동그라미 하나 "마우스가 이 칸에 있음"을 나타내는 동그라미 하나 "1101"이라고 적힌 동그라미 하나
링크 노드와 노드를 잇는 선. "이 행동을 하면 다음 사진으로 넘어간다"는 화살표 한 칸 앞으로 이동하는 행동 A 스위치를 누르는 행동(화살표에 "A"라고 적힘)

미로 찾기 문제 pathfinding

마이크로마우스는 미로의 모습을 미리 알 수 없다. 서로 다른 세 가지 알고리즘 — A(고정 명령), B(왼쪽 벽 따라가기), C(목적지까지 거리 활용) — 를 직접 실행해 보고, 같은 미로라도 알고리즘에 따라 탐색 범위와 이동 횟수가 어떻게 달라지는지 비교해 보자.

A 알고리즘: 출발부터 도착까지 정해진 순서(앞으로/좌회전/우회전)를 미리 명령한다 — 이 미로에서는 통하지만, 미로 모양이 바뀌면 다시 작동하지 않는다.
B 알고리즘: 왼쪽에 벽이 있으면 그 벽을 따라가고, 왼쪽이 비어 있으면 왼쪽으로 돌아 나아간다 — 미로 모습을 몰라도 통하지만 경로가 멀리 돌아갈 수 있다.
C 알고리즘: 각 칸에 목적지까지 남은 거리를 매기고, 항상 더 가까운 칸으로 이동한다 — 막다른 길이면 되돌아가며, 대체로 A·B보다 효율적인 경로를 찾는다.

전구 켜기 문제 state search

스위치 A, B, C, D를 눌러 전구 ①~④를 모두 켜 보자. 스위치 하나를 누르면 그 스위치와 연결된 전구 3개의 상태가 반전(켜짐↔꺼짐)된다.

각 스위치는 서로 다른 전구 3개와 연결되어 있다 — A → ①②④, B → ①②③, C → ②③④, D → ①③④. 같은 스위치를 두 번 누르면 원래 상태로 되돌아오므로, 중요한 것은 각 스위치를 누르는 횟수의 홀짝(0 또는 1번)이며 순서는 결과에 영향을 주지 않는다.
